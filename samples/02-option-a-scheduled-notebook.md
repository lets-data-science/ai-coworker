Option A: scheduled notebook

The analyst would write a Python notebook that reads the sales database and emails each manager a PDF for their region. It runs on the team's existing server on a Monday 7:00 schedule.

Cost: no new licence. Server time is already paid for.
Effort: about four days to build and test.
Maintenance: the code lives in the team repository. Two people on the team can read Python.

Unknowns: we have not checked whether the server can send email, or what happens to the schedule during the quarterly server update.
